# 🚗 Car Resale Price Prediction

A Machine Learning-based web application that predicts the resale price of a used car based on its features and specifications.

## 📌 Project Overview

Car Resale Price Prediction uses Machine Learning to estimate the selling price of a used car. Users can enter car details through a React frontend, and the backend processes the information using a trained ML model to generate a predicted resale price.

## ✨ Features

- Predict used car resale prices.
- User-friendly React frontend.
- Python-based Machine Learning backend.
- REST API integration between frontend and backend.
- Data preprocessing and feature engineering.
- Model-based price prediction.

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Frontend | React.js |
| Backend | Python, FastAPI |
| Machine Learning | Scikit-learn |
| Data Processing | Pandas |
| Model Serialization | Joblib |

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone -b Car-Resale-Price-Prediction-Project https://github.com/DevShah2k6/PythonWork.git
```

### 2. Navigate to the Project

```bash
cd PythonWork
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Backend

Navigate to the backend directory and run the appropriate application entry point.

### 7. Run the Frontend

Navigate to the frontend directory:

```bash
npm install
npm run dev
```

## 🚀 How It Works

1. User enters the car details.
2. Frontend sends the information to the backend API.
3. Backend preprocesses the input data.
4. Trained Machine Learning model predicts the resale price.
5. Predicted price is displayed on the frontend.

## 🎯 Project Objective

The main objective is to simplify used car price estimation using Machine Learning and provide users with an estimated resale value based on vehicle specifications.
